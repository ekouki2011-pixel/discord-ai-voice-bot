# Discord・iPhone実機チェック

以下は所有者のテストサーバーで行う確認です。トークン・招待・実VC・iPhone実機が必要なため、開発時の自動テストとは別です。実施していない項目にチェックを付けて完成扱いしないでください。

## P0

- [ ] コマンド登録後、iPhoneのDiscordで `/join` `/say` `/leave` が候補に出る。
- [ ] 通常VCへ入り `/join`。Botが同じVCへ参加し、AI音声の案内が操作チャンネルに出る。
- [ ] 管理者がVOICEVOX一覧を同期し、利用可能なスタイルを許可する。
- [ ] `/voice set` → `/say text:こんにちは。日本語の読み上げです。`。参加者が明瞭な音声を聞ける。
- [ ] Discordの現行DAVE暗号化が有効なVCで再生できる。依存ライブラリがロードできることと、この実再生は別の確認である。
- [ ] `/volume value:30` と `70` の音量差を確認する。
- [ ] `/leave` でBotが退出し、音声が止まる。

## P1：既存「私の声1」

- [ ] 適格な運用者がSaydiVoiceのAPIプラン・音声の利用許諾を確認してキーを設定する。
- [ ] `/voice sync engine:saydi` で「私の声1」の実IDとready状態が表示される。
- [ ] 同期の前後でMy Voicesの件数・既存音声が維持される。
- [ ] 音声利用を許可し、エンジン・音声を選んで `/say`。既存音声で日本語を再生できる。
- [ ] 認証エラー、利用枠不足、レート制限をサービスが返す場合、Botが理由を示して動作を継続する。実アカウントで故意に制限を超える必要はない。

## P2：自動読み上げ・個人設定

- [ ] Message Content Intentを正規に許可し、環境変数を有効にして再起動する。
- [ ] `/channel set` → `/auto on`。専用チャンネルへ普通に投稿すると読み上げる。
- [ ] 同じチャンネルへ「一番」「二番」「三番」と連続投稿し、追い越し・割り込みがない。
- [ ] 別チャンネルへの投稿、Bot投稿、Webhook、VCに参加していない人の投稿を読み上げない。
- [ ] 長文・連投上限に達した際、上限を超えるAPI送信が発生しない。
- [ ] AとBがそれぞれ別エンジン・声を選び、同じ専用チャンネルで投稿者の設定が使われる。
- [ ] 個人設定のないCにはサーバー既定が使われる。
- [ ] 生成が遅い文章に `/skip`。遅れて戻った音声が再生されず、次の文章に進む。
- [ ] `/stop` で生成・再生・待機が止まる。その後の新規投稿は通常どおり読み上げる。
- [ ] `/auto off`、`/admin pause enabled:true`、対象チャンネル変更で既存待機列も止まる。
- [ ] Bot再起動後にチャンネル設定、個人音声、音量、話速、管理上限が残る。
- [ ] 人が全員退出すると待機列が止まり、設定時間後にBotも退出する。
- [ ] 生成中に投稿者がVCを退出した場合、生成済みの本文を残りのVCへ流さない。

## P3：追加エンジン・権限

- [ ] 管理権限のない人は /admin、/channel、/auto、/voice sync、音声許可、scope:serverを変更できない。
- [ ] 一般ユーザーは他人の個人設定を変更できない。
- [ ] 許可済みVOICEVOXを代替に設定しても、本人がfallbackを許可しなければ別の声へ切り替わらない。
- [ ] 本人が許可した場合だけ、障害時に切替通知が出て代替音声で再生される。
- [ ] 高さ調整非対応エンジンでは説明が出て設定を保持する。
- [ ] ElevenLabsは年齢・利用資格を満たす運用者だけが音声同期・日本語生成・利用量確認を実施する。
- [ ] Fish Audioは許可済み保存モデルIDで日本語音声を生成する。
- [ ] 一時的な通信断から接続が復旧する。復旧失敗時は待機列を止め、再度 /join で回復できる。
- [ ] 外部からBotを別VCへ移動した場合、旧チャンネルの待機音声を新VCへ流さない。

## P4：常時稼働

- [ ] DockerビルドとCompose起動に成功する。
- [ ] readyzが接続時200、Discord未接続時503になる。
- [ ] ホスト上でプロセスを異常終了させ、再起動後の設定保持を確認する。
- [ ] テスト用DBへバックアップを復元して一致を確認する。
- [ ] 実際の停止・失敗・正常終了後に一時音声ディレクトリが消える。
- [ ] ログに読み上げ本文・APIキー・Botトークンが出ていない。
- [ ] `/help` と音声一覧・設定画面から話者のクレジットを確認できる。
- [ ] 無料枠・日次文字数上限と外部サービスの請求設定を確認する。
